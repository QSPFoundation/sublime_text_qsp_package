# Скрипты контроля подсветки QSP

Папка `_disdocs/syntax_highlighting/`. Все скрипты работают относительно корня
репозитория (пакет — в `QSP.sublime-package/`), кириллица в выводе не должна
ронять их на консоли без UTF-8 (при необходимости `$env:PYTHONIOENCODING='utf-8'`).

## Единый гейт (запускать после любой правки в `qsp_base.sublime-syntax`)

```bash
python _disdocs/syntax_highlighting/check_all.py      # ожид.: RESULT: PASS
```

- **`check_all.py`** — единый гейт перед коммитом (аудит п.29). Подряд зовёт три
  проверки ниже через `subprocess`, печатает общий вердикт; exit 0 — все зелёные,
  1 — хотя бы одна FAIL. Осознанно НЕ делает: `gen_braced.py --write` (это
  регенерация, не проверка) и живой Syntax Test в Sublime (headless не стартует).

## Постоянные проверки (вызываются из гейта; можно и отдельно)

- **`check_syntax_phase1.py`** — статический контроль синтаксисов: YAML-load с
  запретом дубликатов ключей (Sublime берёт первый, PyYAML — последний), резолв
  `include`/`push`, баланс скобок в regex, проверка переменных (висящих `{{...}}`
  и неиспользуемых), парность plain/braced-контейнеров (п.5.1) и побайтовая
  сверка braced-региона (импортирует `gen_braced`). Отдельный запуск:
  `python …/check_syntax_phase1.py` (опция `--root <путь>`).
- **`check_syntax_asserts.py`** — контроль scope-ассертов в `syntax_test_*.qsps`
  и `syntax_test_*.qloc` БЕЗ Sublime: ловит «инертные» ассерты без `//`, вылет
  кареток за конец строки, каретки на пробеле, слишком широкие спаны
  `punctuation.*`/`meta.*`, цели вне локаций, `<-` на отступленной цели.
  Запуск: без флага — отчёт (exit 1 при проблемах); `--write` — чинит механически.
- **`gen_braced.py`** — генератор braced-зеркал тела `{…}` в guarded-регионе
  `# @begin-generated … # @end-generated` (Sublime не умеет параметризовать
  `include`, поэтому у каждого контейнера два экземпляра; разница — только
  суффикс `_braced`, исключение `comments → comments_in_brace`). Источник правды
  — plain-контексты с маркером `# @braced: auto`; регион руками не правится.
  Режимы: `--check` (по умолчанию, регион == перегенерация?), `--write`
  (перегенерировать), `--verify` (одноразовое доказательство нейтральности при
  переходе на генерацию).

## Удалённые разовые скрипты (задача выполнена)

- **`_patch_inline_brackets.py`** — разовая правка фикстур под Фазу 10
  (пунктуация однострочных скобок). Применило изменение — не нужно.
- **`convert_assert_prefixes.py`** — разовая конвертация scope-ассертов из
  `^^^` / `! ^^^` в читаемый Sublime формат `// ^^^` (колонка 0 → `// <-`).
  Все фикстуры уже в `//`-формате, генератор-источник утрачен (п.27) — не нужно.
- **`normalize_lazy_ws.py`** — разовая нормализация `\s*?` → `\s*` в `qsp_base`
  (P1.7) с классификацией вхождений и доказательством 1:1 на корпусе. П.7 закрыт —
  не нужно.
