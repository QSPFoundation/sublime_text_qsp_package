# example_syntax_qsrc — фикстура формата `.qsrc`

Папка для ручной проверки подсветки формата **qsrc** (один файл = одна локация).

## Файлы
- `sample_location.qsrc` — покрывает основные scope'ы тела локации:
  переменные/системные величины, операторы, функции, неявные вызовы `@`/`@@`,
  строки с подвыражениями `<< … >>`, инлайн-блоки `{ … }`, `IF/ELSEIF/ELSE`,
  `LOOP … WHILE … STEP`, многострочный `ACT … END`, метки, HTML `<qhtml>`,
  перенос длинной строки через `_`, комментарии.

## Как проверять в Sublime Text
1. Открыть `sample_location.qsrc` — синтаксис должен подхватиться по расширению
   `.qsrc` (в меню также доступен как «QSP»).
2. Весь файл — тело ОДНОЙ локации: подсветка идёт от начала до конца файла,
   блоков `# … --` нет.
3. Две служебные строки в конце (`# Похоже на заголовок…` и `- Похоже на конец…`)
   должны подсвечиваться как **самостоятельные statements**
   (маркеры `avs_locstart` / `avs_locend`), НЕ открывая/не закрывая блок — код
   после них продолжает подсвечиваться как тело.
4. Console (View → Show Console) — без ошибок компиляции синтаксиса.

Фикстура служит ориентиром при правках `qsp.qsrc.sublime-syntax` / `qsp_base.sublime-syntax`.
